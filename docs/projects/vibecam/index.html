VibeCam

An offline pocket-camera simulator with six compact-camera-inspired looks for photos and short videos. Import, compare and restyle while keeping the original.

View repository Project evidence

The project

VibeCam is an iPhone camera app in development, focused on offline photo and short-video looks. Users can capture or import a photo, compare different looks and preview adjustments before applying an edit.

Technical approach

The Expo, React Native and TypeScript app uses local photo rendering and a custom iPhone module for short video export. Film Roll retains originals and applied edits, so users can restyle media without compounding an earlier edit. Cloud features are disabled by default for the first release.

Design decisions

Keeping the original separate from the edit lets people change their mind. The same committed media is used for preview, saving and sharing, helping the output stay consistent with the applied edit.

Evidence

The release-readiness document records development tests, rendering checks and browser walkthroughs. It also provides a physical iPhone walkthrough for capture, audio, export, storage and permissions.
