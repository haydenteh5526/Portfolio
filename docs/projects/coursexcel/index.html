CourseXcel

View repository Project evidence

The project

As Team Leader, I worked on CourseXcel from September to December 2024. The application supports course administration, subject assignments, part-time lecturers and monthly claims, with different workflows for administrators, programme officers and lecturers.

Technical approach

The web application uses Python, Flask, JavaScript and MySQL. It automates course-structure conversion and cost calculations alongside subject assignments, lecturer claims and departmental reports. Role-based permissions keep each workflow aligned with the user’s responsibilities.

Design decisions

Separating the workflows by role keeps each user’s actions and information aligned with their responsibilities. The project shows my interest in practical business software alongside AI applications.

Evidence

The public repository describes the role-based workflows and contains the application source. My CV records my Team Leader role and the project’s work on course-structure conversion and workflow automation.
