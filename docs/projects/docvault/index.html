The project

DocVault is my final-year project: a document management app for digitising physical manuals, warranties and guides and finding information within them. It connects document storage and text extraction with search and document-grounded Q&A.

Technical approach

A React and TypeScript client connects to a FastAPI backend. PostgreSQL full-text search and pgvector provide keyword and semantic retrieval in the same database. Redis and an ARQ worker handle document processing in the background, with an inline fallback when the queue is unavailable.

Design decisions

Combining relational data and both search methods in one database keeps the architecture simpler. Background processing lets uploads return while text extraction and indexing continue.
